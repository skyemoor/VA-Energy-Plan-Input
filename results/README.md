## `hourly_dispatch/`

Hourly dispatch for Scenario 1 checkpoints, April–March hydrological year convention.
Columns: demand, nuclear, wind, solar (new/existing/total), gas, storage charge/discharge/SoC
by technology, curtailment, unserved.

| File | Checkpoint |
|---|---|
| `VA_2030_Scenario1_hourly_FINAL.csv` | 2030 |
| `VA_2035_Scenario1_hourly_FINAL.csv` | 2035 |
| `VA_2040_Scenario1_hourly_FINAL.csv` | 2040 |
| `VA_2044_5_Scenario1_hourly_FINAL.csv` | 2044.5 |
| `VA_2045_TRUE_FINAL_ZeroCurt_hourly.csv` | 2045 |

**Check `registers/Provenance_Register.xlsx` before citing any figure derived from these.**
Some rest on assumptions since revised. Earlier variants of these files (`_FIXED`, `_FORMATTED`,
non-`_FINAL`) are deliberately not included — they were superseded during development.
